# Olnar Bingo

Olnar Bingo is an online multiplayer Bingo platform.

## Features

- Telegram Bot
- FastAPI Backend
- Firebase Database
- Wallet System
- Deposit and Withdrawal Requests
- Online Bingo Rooms
- Automatic Number Drawing
- Automatic Winner Detection
- Admin Dashboard
- Android App (planned)

## Technologies

- Python
- FastAPI
- Firebase
- Telegram Bot API
- GitHub
- Render
